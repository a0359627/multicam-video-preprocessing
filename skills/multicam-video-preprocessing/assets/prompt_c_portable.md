# 多機位訪談剪輯：Test C 通用規則

分析完整的已同步多機位網格影片。依畫面中的 CAM1、CAM2 等標籤識別機位；
依嘴型、發話、視線及實際對話判斷主持人、來賓或其他角色。
不得從機位編號預設人名、衣著、主持人位置或訪談主題；沒有根據時在報告標明不確定。

## 剪輯順序

1. 找出正式開場與結尾，排除工作人員倒數、試音及收工閒聊。
   起點必須保留第一句的完整字音；不可為了排除倒數而切掉開場第一個字。
2. 開場介紹期間持續使用實際主持人機位，直到主持人完成介紹並交出發話權。
   不按固定秒數結束開場鎖定。
3. 正片以主講者為主；另一人實質接話時換鏡。短暫附和不強迫換鏡。
4. 主講者說了約 45–60 秒後可以尋找反應鏡頭，但這只是搜尋窗口。
   必須同時有語意停頓與聆聽者明確反應（微笑、點頭、驚訝等），才切入約 2.5–4 秒，
   再回主講者。沒有自然機會就繼續主講者；不得為達到固定間隔製造反應或硬切。
5. 相鄰且時間連續的同機位片段合併，避免假性自切。不得為消除自切而補回原本刪掉的內容。
6. EDL 使用輸入網格影片的原始時間座標，不先扣除開場時間；匯出器會將成片起點歸零。
   頭尾裁切以外的正常對話必須完整連續，不得用大段補齊掩蓋未分析的片段。
7. 畫面選擇與聲音分開：反應鏡頭期間聲音仍應保留主講者，不假設切機位就是換收音來源。

## 輸出

先輸出簡短繁體中文報告：正式開始/結束時間、各 CAM 角色對應與不確定處、重要切鏡理由。
接著輸出一個 CSV 程式碼區塊，欄位必須是：

```csv
Start_Time,End_Time,Best_Camera,剪輯規則,剪輯原因
```

時間使用 MM:SS.mmm 或 HH:MM:SS.mmm；所有時間必須來自本次影片。
第一筆 Start_Time 是正式開場，最後一筆 End_Time 是正式結尾。
每一筆結束晚於開始、依時間排序，不重疊；相鄰鏡頭時間連續。
使用實際存在的 CAM 編號，不輸出示意資料或沿用其他訪談的人名、時間與情節。
